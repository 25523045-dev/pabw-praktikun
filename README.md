## Worksheet P4 — Design Token Halaman Profil

Berkas gaya:

- `tokens.css`
- `base.css`
- `layout.css`
- `komponen.css`
- `tema.css`

Implementasi menggunakan dua lapis token: primitive dan semantic. CSS layout menggunakan Flexbox dan `gap`, tipografi menggunakan `rem`, gambar responsif, form memiliki `focus-visible` dan validasi pengguna, serta tema gelap dapat mengikuti preferensi sistem atau diaktifkan dengan tombol.

Perubahan `--color-primary` pada token semantic dapat mengubah komponen yang menggunakannya.
